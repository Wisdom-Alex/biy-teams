Skills Campers Build Across All 7 Build-It-Yourself Concord Academy Camps

Core Problem‑Solving Skills (All Camps)

  1. Define a problem and set clear goals
  2. Research and gather useful information
  3. Work effectively in teams
  4. Break big challenges into simple, solvable parts
  5. Document - work like real engineers
Presentation - Communication (All Camps)

  1. Speak clearly, concisely, and confidently
  2. Design clean, compelling PowerPoint slides

Camp‑Specific Skills

Scratch Music
Project Page

  1. Programming fundamentals and logic

  3. How scales, chords, and math connect

Scratch Games
Project Page

  4. Sound engineering for games

Pirate Ships

Super Hero Robots
Project Page

Nature Engineering
Project Page

Typical Camp Day:

  1. Review problem, mission, and tricks learned
  2. Intro to new task
  3. Exercise task
  4. Present and critique task
  5. Break for lunch and swim
  6. Intro to new task
  7. Exercise task
  8. Present and critique task
  9. Clean up

At the end of the week, campers must present their lab books and solutions in a video recording.
